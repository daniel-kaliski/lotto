# lotto
Skrypt analizuje historyczne losowania lotto, a następnie wyświetla: 
1 - Najczęściej występujące liczby (Top 10)
2 - Zalecane zestawy (po 6 liczb)
3 - Najczęstsze kombinacje w symulacji (Top 4 z 14 000 000 symulacji)

Aby uruchomić skrypt Python, otwórz terminal lub wiersz poleceń, przejdź do folderu ze skryptem (cd), a następnie wpisz python lotto.py i naciśnij Enter. Na macOS w terminalu wpisz python3 lotto.py
